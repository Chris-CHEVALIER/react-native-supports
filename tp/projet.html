1 Ce que l'application doit contenir

Obligatoire

  • Au moins 4 écrans, organisés avec Expo Router : des onglets, une pile et au moins une route dynamique (par exemple /items/[id]).
  • Sur le web, l'URL suit la navigation : une page de détail s'ouvre directement depuis son adresse.
  • Un catalogue responsive : une grille sur ordinateur, une liste fluide sur téléphone, avec des filtres dont la logique vit dans un hook.
  • Une API publique consommée avec fetch(), avec les états de chargement et d'erreur.
  • Firebase : authentification par e-mail et deux CRUD (créer, lire, modifier, supprimer) sur deux collections différentes.
  • Une architecture MVC en TypeScript : modèles typés, services, hooks contrôleurs, composants d'affichage purs.
  • Une interface lisible et cohérente : hiérarchie visuelle, contrastes suffisants, retours visuels au toucher.
  • Un README.md complet (voir la partie 4).
Une application qui ne se lance pas sur le web ou sur Expo Go ne peut pas être évaluée. Testez les deux à chaque commit important.

Valorisé (bonus)

  • Une API native du téléphone : caméra, localisation, notifications, retour haptique…
  • Des animations soignées.
  • Un cache ou un mode hors ligne.
  • Des tests automatisés des fonctions du modèle.
  • La version web déployée en ligne.
  • Une bibliothèque d'état (Zustand, TanStack Query…), si vous savez expliquer ce choix.

5 Le dépôt et le rendu

  • Un dépôt GitHub privé nommé rn-projet-nom1-nom2-nom3, avec Chris-CHEVALIER invité dès le premier jour.
  • Chacun commite avec son propre compte, régulièrement. L'historique me sert à mesurer la contribution de chacun.
  • Le projet se lance avec npm install puis npx expo start, sans autre manipulation. Aucun fichier APK ou IPA n'est demandé.

Le README contient

  • le sujet, les membres du groupe et le propriétaire de chaque partie ;
  • les fonctionnalités, avec des captures d'écran sur le web et sur mobile ;
  • l'API publique utilisée et le schéma des collections Firebase ;
  • le parcours de navigation (la liste des écrans et leurs URL) ;
  • les instructions de lancement, dont la configuration Firebase à fournir ;
  • les bonus réalisés ;
  • la déclaration d'usage de l'IA.
